# V23: Gauge-fixed GENERIC Mori-JEPA with physical long-horizon K1

Date: 2026-09-19

V23 supersedes the V21 proposal. It is deliberately smaller and more
constrained: one thermodynamic generator is shared by all horizons, and every
extra degree of freedom has a physical invariant or an intervention test.

## 1. Why V21 is not the final model

The V21 idea of adding an independent reversible potential `H` is not safe
enough for a final paper. In general, `J grad(H)` does not preserve the Gibbs
measure generated by `F`; it can improve a forecast while violating the claimed
equilibrium physics. A cosine alignment term also does not identify force from
memory when both branches can explain the same increment. Finally, independent
horizon heads can fit h=32 and h=64 without defining one continuous-time law.

V23 removes all three weaknesses.

## 2. V23 model: one extended GENERIC generator

The JEPA encoder maps a causal structural history to a latent coordinate `q`,
and a protein/temperature condition `c,T`. A causal Mori observer estimates a
small auxiliary state `a` from the history. The joint state is

```text
y = (q, a),        H(y|c,T) = F(q|c,T) + 1/2 ||a||^2.
```

The dynamics is one thermodynamic GENERIC SDE:

```text
dy = [(J(c,T) - M(c,T)) grad_y H] dt
     + sqrt(2 k_B T M(c,T)) dW.
```

Use the block operators

```text
J = [[ J_q,  C ],        M = [[ D, 0 ],
     [-C^T, A ]],             [ 0, S ]],
```

where `J_q` and `A` are skew-symmetric, and `D` and `S` are PSD. This gives

```text
dq = (-D grad F + J_q grad F + C a) dt + noise_q
da = (-S a - C^T grad F + A a) dt + noise_a.
```

The same `F` appears in both q and a equations. There is no independent
reversible energy head. With operators constant in `q` for a fixed protein and
temperature, the skew part is divergence-free and the invariant measure is

```text
p_eq(q,a | c,T) ∝ exp[-H(q,a|c,T)/(k_B T)].
```

`D` and `S` are represented by Cholesky/low-rank factors with a positive floor.
`C` is QR gauge-fixed with positive diagonal; bath rates are sorted. These
constraints remove the scale/rotation ambiguity that made the old bath and
force branches compete. If a future version makes `D` depend on `q`, it must
add the exact Ito correction `k_B T div(D)`; V23 does not silently omit it.

The projected Mori kernel is now a consequence of the generator,

```text
K(t | c,T) = C exp[-(S-A)t] C^T,
```

rather than an unconstrained history residual. This is the main physical
innovation of V23: JEPA learns a reaction coordinate and a gauge-fixed,
thermodynamically admissible memory generator jointly.

## 3. Numerics and horizon transfer

Do not use Euler integration for the promoted model. Use a Strang split:

1. exact OU half-step for the dissipative block `(D,S)`;
2. implicit-midpoint/Cayley step for the skew block `(J_q,C,A)` using the
   midpoint gradient of `F`;
3. exact OU half-step again.

For locally frozen coefficients, compute the joint transition and covariance
with the existing Van Loan exponential. The same generator is exponentiated
for every horizon. In particular, h=64 is not a separately trained head:

```text
P_64 = P_32 ∘ P_32 = exp(2 Δt_32 G),
```

and the semigroup residual is a first-class training/evaluation quantity.

## 4. Identifiability objective

The loss is organized around interventions, not a larger MSE:

```text
L = L_JEPA
  + 1.00 L_full_transition_NLL
  + 0.25 L_force_residual
  + 0.15 L_memory_intervention
  + 0.10 L_semigroup
  + 0.10 L_equilibrium_score
  + 0.05 L_detailed_balance
  + 0.05 L_horizon_order.
```

Definitions:

- `L_force_residual`: infer `a_t` only from the causal history, detach that
  estimate, and fit the `a=0` force-only increment to the residual increment.
  Use a whitened Huber loss and a force-direction cosine term.
- `L_memory_intervention`: compare the same current q with real history,
  shuffled history, and truncated history. The predicted difference must equal
  the `C a` contribution and must vanish under an independently shuffled
  history. This is the anti-collusion test for the memory branch.
- `L_equilibrium_score`: score matching on the observed current q using the
  same temperature-explicit `F`; the target is never produced by the model's
  own untrained potential.
- `L_detailed_balance`: forward/reverse transition log-ratio agrees with the
  free-energy difference for the dissipative substep; the skew substep has zero
  energy production by construction.
- `L_horizon_order`: a same-context h=32/h=64 pair is trained through the same
  generator and checked by semigroup composition, not by forcing a monotone
  scalar displacement (which is not generally physical).

The required ablations are `M0` (D only), `M1` (D+F), `M2` (D+Mori bath), and
`V23` (full block GENERIC). Every ablation uses the same encoder, data split,
and exact transition code.

## 5. Final training schedule

The schedule is intentionally short enough to diagnose failure:

| Steps | Trainable components | Purpose |
|---:|---|---|
| 0–600 | JEPA predictor + causal Mori observer | establish non-collapsed q/a and log memory intervention |
| 600–1600 | `F` and `J_q`; `D,S,C,A` frozen | identify conservative/reversible drift after bath subtraction |
| 1600–3200 | all generator factors | fit exact NLL, FDT, equilibrium score, and detailed balance |
| 3200–5000 | all factors + encoder at 0.05× LR | closed rollout and h=32/64 semigroup transfer |

Checkpoint selection is validation-only. If the force residual cosine is still
near zero or memory fraction is above 0.90 at step 1600, stop; do not increase
capacity. The data then do not identify a force at this sampling rate.

For the mdCATH training sampler, use paired horizons `[32, 64]` plus one
composition control `[16]` (so 16+16 can be checked against 32). Use a context
span shorter than 32 raw frames and `paired_all_horizons=true` so the same
context is evaluated at every horizon.

## 6. K1 final protocol: h=32 and h=64

The main K1 task is now exactly h=32 and h=64. Keep the corrected q-native
labels, scaffold-disjoint split (seed 6303), train-scaffold-only readout, fixed
ridge readout, and protein/scaffold bootstrap. Historical h=1/4 results remain
an appendix diagnostic and are not part of the primary claim.

There is one necessary protocol correction. The current labels contain 100
non-uniformly spaced snapshots per trajectory; adjacent raw-frame gaps have
roughly 0.26–0.35 coefficient of variation. Therefore every sample must record

```text
delta_frame = target_frame - source_frame
delta_time_ps = delta_frame * saved_frame_interval_ps
```

and the report must include the distribution of `delta_time_ps` for each h.
The primary h=32/h=64 comparison is valid only if the same physical-time bin
is used across methods. If the labels are kept as index lags, call them
“nominal sampled-step horizons” and report the physical-time spread; do not
call them a single 32-step or 64-step physical time.

Primary metrics:

1. pooled and per-protein implied-timescale error;
2. MFPT relative error with a censoring-aware confidence interval;
3. semigroup residual `||P_64-P_32^2||`;
4. q-native endpoint energy skill and continuous progress RMSE;
5. folded-event Brier/AUC and calibration as secondary metrics.

Required controls are Persistence, MajorityClass, train-fitted MSM,
train-fitted tICA+MSM, and a continuous OU/VAR baseline. h=64 has fewer
independent test events, so protein/scaffold bootstrap and a minimum event/state
count must be printed; a single pooled number is not sufficient.

## 7. Promotion gates for the final paper

V23 is promoted only if validation satisfies all hard gates:

- finite exact/Strang rollout; diffusion condition number < 100;
- FDT residual below the Monte-Carlo sampling floor, not merely below an
  arbitrary raw threshold;
- memory intervention advantage > 0 and force residual cosine > v20;
- `P_64` agrees with `P_32^2` within the pre-registered tolerance;
- on h=32 and h=64, V23 beats Persistence and MajorityClass on NLL/continuous
  progress, and beats the best MSM/tICA+MSM on at least one of ITS or MFPT with
  a protein-bootstrap interval excluding zero;
- no horizon has a degenerate rank-one operator or a vanished variance;
- the sign of every primary improvement agrees across three seeds.

If these gates fail, the final manuscript claim is the honest one: a stable,
thermodynamically constrained stochastic JEPA with competitive long-time ITS,
not a universally superior protein kinetics model. This boundary is part of the
V23 design, not a post-hoc fallback.
