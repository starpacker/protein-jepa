## Executive Summary

Phase 8N/N14 is the current endpoint-calibrated internal SOTA for TM-JEPA V3. It keeps the G-750 overdamped thermodynamic dynamics unchanged and applies a bounded horizon/temperature-dependent endpoint variance renormalization around the rollout ensemble mean.

This improves probabilistic endpoint skill and fixes the per-temperature 90% marginal coverage gate across three evaluation seeds. It does not fix Markov closure, innovation whiteness, CK consistency, MSM readout, or VAMP slow-mode quality, because those depend on the underlying transition kernel and representation rather than endpoint sample variance alone.

Accurate claim:

> N14 is the current internal SOTA for calibrated endpoint rollout energy skill under the Phase-8 TM-JEPA V3 validation protocol. It is not a fully promotion-passing physical-closure model.

## Calibration Parameters

N14 was generated by:

```bash
PYTHONPATH=/liuyutian/protein_jepa_frame /liuyutian/protein_jepa/.venv/bin/python scripts/make_phase8n_analytic_calibration.py \
  --base-checkpoint artifacts/phase8g_tmjepa_v3_overdamped_longhorizon/checkpoint_step750.pt \
  --output artifacts/phase8n_tmjepa_v3_analytic_calibration/checkpoint_analytic_n14.pt \
  --bias 0.172 \
  --log-horizon-slope -0.345 \
  --short-horizon-slope 1.500 \
  --short-temperature-slope -0.200 \
  --calibration-scale 0.5 \
  --temperature-scale 6.0
```

The calibrator rescales sample deviations around the ensemble mean:

`sample = mean + exp(log_scale(horizon, temperature)) * (sample - mean)`

Therefore it changes uncertainty, coverage, and energy score, but it does not move the predicted mean and does not change the path innovation statistics.

## Next Technical Target

The next real model improvement should target path closure, not more endpoint calibration. The first-principles reason is that the remaining residual is concentrated at lag 1: the transition kernel is missing short-memory or unresolved fast-coordinate structure. A scientifically clean next branch should add a learned lag-1 innovation correction or short-memory kernel with a whiteness/covariance objective, while keeping the N13/N14 endpoint calibrator as the observation-level uncertainty correction.
