# Local trajectory manifests

Trajectory manifests are machine-specific because each JSONL record points to
local molecular-dynamics data. They are ignored by Git.

The canonical V4-D configs expect the mdCATH training manifest at:

```text
manifests/mdcath.train.jsonl
```

Validation and test manifests are passed explicitly to evaluation scripts so
that calibration and independent testing cannot be confused.

TM-JEPA uses replica- and temperature-held-out pilot manifests generated by
`scripts/build_tmjepa_pilot_manifests.py`:

```text
manifests/tmjepa_pilot20.train.jsonl
manifests/tmjepa_pilot20.validation.jsonl
manifests/tmjepa_pilot20.test.jsonl
manifests/tmjepa_pilot20.temperature_test.jsonl
```

The training split contains replicas 0-2 at 320-413 K. Replica 3 is validation,
replica 4 is test, and every 450 K trajectory is reserved for temperature
extrapolation.
