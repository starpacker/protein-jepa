核心思想：从分子动力学轨迹中学习一个可迁移的蛋白动力学世界模型。Stage A 通过 JEPA 自监督学习残基级的时空表示；Stage B 在该潜空间中学习符合物理约束的随机动力学（保守力、状态依赖扩散、Mori-Zwanzig 记忆浴）；Stage C 将预测的潜状态解码为蛋白物理可观测量和全原子结构。三个阶段各自冻结、独立评估、可组合验证。

A Stage A — JEPA 表示预训练

目标

以完全不标注的 MD 轨迹为输入，自监督地学习每个残基在每个时刻的隐藏表示 H ∈ ℝ²⁵⁶，使该表示能够 (a) 从可见残基预测被遮挡的残基，(b) 从当前窗口预测未来状态。

架构

Spatial Encoder (ProteinGeometryEncoder)

  • 输入: [B,T,L,4,3] backbone 坐标 (N,CA,C,O)
  • 特征: 内骨架距离 (6 类) + sin/cos(φ,ψ,ω)
  • 层: GNN (VisibleGraphAttention) + Transformer
  • 输出: H ∈ [B,T,L,256] 每残基每帧表示

Temporal Encoder (TemporalStateEncoder)

  • 输入: H (来自 spatial encoder) + time_ps, T_k
  • Pooling: mean(valid residues) per frame
  • 层: Transformer Encoder (depth=2)
  • 时间条件: physical (LogTimeEmbedding)
  • 输出: clip_state [B,D] + frame_states [B,T,D]

损失函数

LStage A = Lresidue_JEPA + 0.25·Lstate_JEPA + 1.0·Lpaired_delta + 0.25·Lpaired_state + 0.01·(Lvariance_reg + Lstate_variance + Lstate_feature_var) + 0.02·Lstate_covariance

Lresidue_JEPA 和 Lstate_JEPA 使用 EMA target encoder (momentum: 0.996→1.0) 作为教师；Lpaired_delta 是时域终点预测，强制 encoder 学习多时间尺度的变化信息。块状时空掩码控制可见比例为 15%-50%。

关键突破: 时间条件修复

🔑 诊断: Smoke encoder 产生全同表示 cos(Ht, H0) ≈ 0.999999

所有帧被映射到几乎相同的 H，导致所有动力学模型等效为一个 Persistence baseline（恒等映射）。空间编码器逐帧独立处理、蛋白 backbone 在短窗口内几何变化微弱，两者共同导致了表示的时间崩塌。

修复方案修复前修复后改善
time_conditioning="physical" (LogTimeEmbedding 注入 temporal encoder) — — 核心机制
宽帧间隔: stride=4 (每 4ns 一帧), 8 帧窗口 = 28ns 跨距 stride=1 (1ns) stride=4 4× 增大
多时域预测: 16ns, 32ns, 64ns 三个 horizon 单一 horizon 3 horizons 强制多尺度
cos(S0, S10ns) — 时间状态余弦相似度 0.999999 0.476 从全同变为显著衰减
cos(S0, S40ns) 0.999999 0.463 真正的时变表示
cos(clip320K, clip450K) — 温度分离 0.999999 0.758 温度条件被编码
⚠️ 空间编码器 H 依然时不变 (cos≈0.999)

这是预期行为——蛋白 backbone 在 10-40ns 内的局部几何变化太小，空间编码器不应为此改变表示。时间敏感性完全由 temporal encoder 承担。

B Stage B — 潜空间朗之万动力学 (LSP-WM)

目标

在冻结的 Stage A 编码器之上，学习一个物理一致的低维随机动力学模型。learned_projection 将 H ∈ ℝ²⁵⁶ → Q ∈ ℝ⁸（每残基动力学变量），G = mean(Q) ∈ ℝ⁸。在 Q 空间中学习保守力势能 + 状态依赖扩散 + Mori-Zwanzig 有限浴记忆核。最终得到一个可自主 rollout 的随机过程，无需访问未来帧。

Mori-Zwanzig 广义朗之万方程

Q(t+Δt) = Q(t) + M · ∇U(Q(t)) · Δt  ← 保守力势能（学习得到） + Στ Kτ · (Q(t−τ) − μ) · Δt  ← Mori 记忆浴（4 组 8×8 核，32ns 历史） + √(2·D(Q(t))·Δt) · ξt  ← 状态依赖扩散（高斯噪声，满足 FDT）
S(t+Δt) = e−ΓΔtS(t) + CT·∇U(Q(t))·Δt + √(2ΓΔt)·ηt  ← 辅助浴演化 (OU 过程)
其中 ξt, ηt ~ N(0,I)；U(Q), D(Q) 为可学习 MLP；M, Γ, C 为可学习矩阵。

LSP-WM 损失体系
